# 👷 `workerd` for Linux 64-bit with musl libc, Cloudflare's JavaScript/Wasm Runtime

`workerd` is a JavaScript / Wasm server runtime based on the same code that powers
[Cloudflare Workers](https://workers.dev).

This package contains the build for musl-based Linux distributions such as Alpine.

See https://github.com/cloudflare/workerd for details.
